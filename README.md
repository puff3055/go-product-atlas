## 给 ChatGPT 的提示词

请先阅读 READING.md，区分现有功能、历史设计与未实现备选，把 IP 陪伴感、缺省状态和操作成本一起考虑，与我讨论最值得优先优化的三个方向；不要写代码，读不到图片时请明确说明。

## 本地阅读与验证

已包含可直接托管的 dist 静态文件，不需要原生工程或构建依赖。运行 `python3 -m http.server 4387 --directory dist` 后打开本地页面；`node check.mjs` 检查链接和静态阅读覆盖。

build.mjs 是原素材整理脚本，需要本地历史素材来源；没有素材时直接使用已发布 dist，不重新生图冒充旧版本。首页是全部展开的长页面，顶部导航只定位本页；旧链接兼容显示同一页面，不存在必须点击进入的二级内容。

普通网页读取不等于浏览器操作；只有具备对应工具和权限的 ChatGPT 模式才能尝试点击输入。完整阅读不依赖这些能力。
